Frotrue · Short-form Blocker

개인정보처리방침

시행일: 2026년 9월 23일 · Android 앱: dev.shortform.blocker

Short-form Blocker는 사용자가 선택한 YouTube Shorts 및 Instagram Reels 시청 화면을 감지해 뒤로 가기를 실행하는 앱입니다. 감지 정보는 기기 안에서만 처리하며, 앱에는 인터넷 통신 권한·광고·분석 SDK가 없습니다.

1. 운영자 및 문의

개발자 및 운영자: Frotrue. 개인정보 관련 문의는 개인정보 문의 페이지에서 접수할 수 있습니다. 이 페이지는 앱의 개인정보 처리 방침만 공개하며 앱 소스 코드를 포함하지 않습니다.

2. 접근성 서비스로 처리하는 정보와 목적

사용자가 앱 내 안내에 동의하고 Android 접근성 설정에서 서비스를 직접 활성화하면, 앱은 YouTube와 Instagram의 화면 이벤트, 패키지·창 식별자, UI 리소스 식별자, 부모·자식 관계, 표시·선택 상태를 읽습니다. 이 정보는 숏폼 전용 시청 화면을 판단하고 해당 화면에서 뒤로 가기를 실행하는 데만 사용합니다.

화면 텍스트, 영상 제목, 댓글·DM 내용, 비밀번호나 입력 내용, 사진·영상·오디오는 읽거나 수집하지 않습니다. 화면을 촬영하거나 녹화하지 않습니다. 접근성 서비스는 사용자의 동의 없이 활성화되지 않습니다.

3. 기기에 저장하는 정보

  • 앱별 차단 설정, 감지 전용 모드, 일시 허용 종료 시각
  • 통계 날짜와 앱별 일일 차단 횟수

위 정보는 기능 제공을 위해 앱 전용 저장 영역에 보관합니다. 마지막 감지 대상·규칙·결과·확인 시각 등 진단 상태와 UI 구조 정보는 실행 중 메모리에서만 사용하며 파일이나 서버에 기록하지 않습니다. 사용자가 본 영상·게시물의 이력을 만들지 않습니다.

4. 외부 전송 및 제3자 제공

앱은 개인정보나 감지 정보를 개발자 서버 또는 제3자에게 전송·공유·판매하지 않습니다. 별도 회원가입, 광고 ID 사용, 광고·사용 분석, 개발자에게 보내는 자동 오류 보고 기능이 없습니다. Android 및 Google Play가 자체적으로 제공하는 서비스의 데이터 처리는 해당 서비스의 정책을 따릅니다.

5. 보관·삭제 및 사용자 선택

설정과 로컬 통계는 앱 데이터가 삭제될 때까지 기기에 남을 수 있습니다. 날짜가 바뀌면 일일 통계를 갱신하며, 과거 일별 기록을 누적 보관하지 않습니다. Android 설정에서 앱의 저장공간 데이터를 삭제하거나 앱을 제거하면 앱의 로컬 데이터가 삭제됩니다. 앱 계정이나 개발자 서버 데이터베이스가 없으므로 별도 계정 탈퇴 절차가 없습니다.

앱별 차단 토글, 일시 허용 기능 또는 Android 접근성 설정으로 언제든 동작을 중지할 수 있습니다. 접근성 권한을 끄더라도 기존 설정·통계가 자동 삭제되지는 않습니다.

6. 보호 조치

Android의 앱 전용 저장 영역을 사용하고 앱의 클라우드 백업을 비활성화합니다. UI 구조는 감지에 필요한 범위와 시간으로 제한하여 기기 내부에서 처리합니다. 앱은 연락처·위치·SMS·카메라·마이크·공용 저장소 접근 권한을 요청하지 않습니다.

7. 이 웹페이지와 문의 서비스

이 정책 페이지는 GitHub Pages에 호스팅됩니다. 페이지 방문 및 GitHub를 통한 문의에는 GitHub 개인정보처리방침이 적용될 수 있습니다. 이 페이지에는 별도의 분석 코드나 광고를 넣지 않았습니다.

8. 변경 안내

기능 또는 데이터 처리 방식이 변경되면 이 페이지의 방침과 시행일을 갱신합니다. 접근성 정보의 이용 목적이 변경되는 경우 앱 내 안내와 필요한 동의 절차도 함께 갱신합니다.
